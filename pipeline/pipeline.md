Шаг 1: "Hello, 3D World!" (v0.1) 

Цель: Создать окно с работающим 3D-контекстом и нарисовать простую фигуру (например, оси координат), чтобы убедиться, что весь стек работает. 

     

    Задачи: 
        Создать главное окно с помощью QMainWindow. 
        Встроить в него виджет QOpenGLWidget. 
        В методе initializeGL настроить цвет фона и базовые параметры OpenGL. 
        В методе paintGL нарисовать три линии (оси X, Y, Z) разного цвета. 
        В методе resizeGL настроить проекцию, чтобы сцена не искажалась при изменении размера окна. 
     

    Результат: Запускаемое приложение, показывающее окно с 3D-осями. 
     

Шаг 2: Статическая модель платформы (v0.2) 

Цель: Нарисовать саму платформу Стюарта в её начальном (нулевом) положении. 

     

    Задачи: 
        Создать Python-класс StewartPlatform. 
        Перенести все константы из вашего скетча (BASE_RADIUS, PLATFORM_RADIUS, BASE_ANGLES и т.д.) в этот класс. 
        В __init__ класса рассчитать начальные позиции точек крепления (b на основании и p на платформе) с помощью numpy. 
        Создать метод draw() в классе StewartPlatform. 
        Внутри draw() использовать команды OpenGL (glBegin(GL_LINES), glVertex3fv(), glBegin(GL_POINTS)) для отрисовки:
             Основания и платформы (как эллипсы или многоугольники).
             Шести стержней, соединяющих основание и платформу.
             Точек крепления (B, A, P).
              
        В основном виджете создать экземпляр StewartPlatform и вызывать его метод draw() из paintGL. 
     

    Результат: Приложение, которое отображает полную, но статичную 3D-модель платформы Стюарта.

Шаг 4: Реализация логики и анимации (v0.4) 

Цель: Связать слайдеры с 3D-моделью. Двигать платформу в реальном времени. 

     

    Задачи: 
        В классе StewartPlatform создать метод update_pose(translation, rotation). 
        Перенести логику из calculateVectorQL и calculateAngleAlpha в этот метод, используя numpy для матричных поворотов. Это будет ядро вашей инверсной кинематики. 
        Метод должен пересчитывать позиции всех точек (q, l, a) и углы alpha на основе новых translation и rotation. 
        В основном классе виджета:
             В обработчиках сигналов слайдеров считывать их значения.
             Вызывать platform.update_pose() с новыми значениями.
             Вызывать self.update(), чтобы перерисовать 3D-сцену.
              
        Реализовать логику для кнопки "Reset", которая устанавливает все слайдеры в 0 и обновляет модель. 
     

    Результат: Полностью интерактивная симуляция. Двигая слайдеры, вы видите, как платформа движется в 3D.

Шаг 6: Управление камерой (v0.6)

    Задачи: 
        В классе 3D-виджета добавить переменные для хранения положения камеры (расстояние, углы поворота). 
        Переопределить обработчики событий мыши: mousePressEvent, mouseMoveEvent, wheelEvent. 
        Реализовать логику:
             Левая кнопка + движение мыши: Вращение камеры вокруг сцены (изменение азимута и высоты).
